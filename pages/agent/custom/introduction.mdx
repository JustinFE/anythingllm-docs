# Introduction to custom agent skills

Methodius AI allows you to create custom agent skills that can be used to extend the capabilities of your `@agent` invocations. These skills can be anything you want from a simple API call to even operating-system invocations.

The sky is the limit! Depending on how you run Methodius AI, you can create custom agent skills that can run extra processes like running a local Python script or, on Desktop, even operating-system invocations.

If it can be done in NodeJS, it can likely be done in Methodius AI.

## The current state of custom agent skills

<Callout type="info" emoji="️💡">
 Custom agent skills are newly supported in Methodius AI and may have some bugs, quirks, missing features, unsupported features, etc.

Please report any feature requests or bugs you find to the [GitHub repository](support.forwardedge.ai).

</Callout>

1. NodeJS programming experience is required to create custom agent skills. Go to the [developer guide](./developer-guide.mdx) to get started.
2. Custom agent skills must _exactly_ match the requirements listed on this help page.
3. There are built in functions and utilities to help you log data or thoughts for an agent.
4. There is currently no established tooling for creating custom agent skills - so follow this guide if developing skills for Methodius AI.
5. All skills must return a `string` type response - anything else may break the agent invocation.

## Availability

Custom agent skills are available in the Docker image since [commit `d1103e`](support.forwardedge.ai) or [release v1.2.2](support.forwardedge.ai).

Custom agent skills are available in Methodius AI Desktop version **1.6.5 and later.**

Custom agent skills are **not** available in the Methodius AI Cloud offering.

## View loaded custom agent skills

You can view the loaded custom agent skills by opening the `Agent Skills` tab in the settings of Methodius AI.

Any valid custom agent skills loaded into Methodius AI will be displayed here.

See [where to place your custom agent skills](./developer-guide.mdx#where-to-place-your-custom-agent-skill-code) for more information.

# Linux Installation

**1. Install using the [installer script](#install-using-the-installer-script)**

## Install using the installer script

<Callout type="warning" emoji="⚠️">
  **NOTICE**

➤ Methodius AI packages as an AppImage but you **will not** be able to boot if you run just the AppImage. Please only use the script below.

➤ Please open a [Github Issue](support.forwardedge.ai) if you have installation or bootup troubles.

</Callout>

First, open a terminal on your Linux machine and run this command.

```shell copy
curl -fsSL https://cdn.Methodius AI.com/latest/installer.sh | sh
```

You can view the raw script contents [here](support.forwardedge.ai).

This will download the latest version of Methodius AI's AppImage, unpack it, and then supply a symlink to seamlessly run Methodius AI.
This script will unpack the app in `$HOME/Methodius AIDesktop`.

You can start the app at any time by running `./Methodius AIDesktop/start`. This will boot the app with full logging.

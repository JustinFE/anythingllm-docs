## General Debugging

If you are having issues with Methodius AI, the first thing you should do is check the logs. You can find the logs in the `logs` folder of your Methodius AI storage - which you can find [on your computer using this guide.](./storage.mdx#where-is-my-data-located)

## Methodius AI Debug mode on MacOS

To run the Methodius AI Application in debug mode (if you are getting errors) you can open a Terminal and navigate to `~/Applications/Methodius AI/Content/MacOs` where you can then run the executable and see all application logs while running Methodius AI.

## Methodius AI Debug mode on Windows

To run the Methodius AI Application in debug mode (if you are getting errors) you can open a CMD or Powershell window and run the path to the Methodius AI executable. Typically this is in `C:\Users\usr\AppData\Local\Programs\Methodius AI-desktop\Methodius AIDesktop.exe`.
This will print all logs to the powershell window while running and should display a verbose error once encountered that is critical for debugging.

## Methodius AI Debug mode on Linux

To run the Methodius AI Application in debug mode (if you are getting errors) you can open a Terminal and navigate to `~/.config/Methodius AI-desktop/Methodius AIDesktop.AppImage` where you can then run the executable and see all AppImage logs while running Methodius AI.

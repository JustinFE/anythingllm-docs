# What is the Methodius Community Hub?

The [Methodius Community Hub](https://hub.Methodius.com) is a platform and marketplace for Methodius users to share system prompts, slash commands, agent skills, and more.

The community hub enables you to share your own items, skills, and workflows with the Methodius community both **publicly** and **privately**.

Currently, the Methodius Community Hub is in **beta** and as such, not all types of items are supported.

### Current Supported Item Types

- [x] Agent Skills
- [x] System Prompts
- [x] Slash Commands

_More item types are coming soon!_

- [ ] Workspaces
- [ ] Data Connectors
- [ ] Authentication Providers

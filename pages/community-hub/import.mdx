# Importing from the Methodius Community Hub

Every item in the Methodius Community Hub can be imported into Methodius. The process for importing each type is mostly the same.

## Locate the item on the Methodius Hub

Given a public or private item on the Methodius Hub, you can get the import string from the item by clicking on the **Import to Methodius** button.

<Image
  src="/images/community-hub/import-button.png"

  height={1080}
  style={{
    margin: "5px",
    borderRadius: "10px",

/>

Clicking this button will show you a modal with the import string for the item.

_On desktop this may prompt you to automatically open Methodius to automatically handle the import via a deep links._

<Image
  src="/images/community-hub/import-modal.png"

    borderRadius: "10px",

/>

Paste the import string into Methodius to begin the import process.

<Image
  src="/images/community-hub/import-Methodius.png"

  width={1920}

  style={{

  }}
/>

From here, you can follow the on-screen instructions to complete the import.

## Failed to import agent skill?

On self-hosted or the dockerized versions of Methodius, you may encounter an error when importing an agent skill.

This is because the agent skill requires you to enable imports of agent skills in the Methodius configuration. By default, this is disabled to prevent malicious users from adding harmful agent skills to your instance.

If you are the administrator of the Methodius instance, you can enable imports of agent skills by modifying the `COMMUNITY_HUB_BUNDLE_DOWNLOADS_ENABLED` configuration value to the appropriate security setting.

See the [configuration page](/configuration#Methodius-hub-agent-skills) for more information.
